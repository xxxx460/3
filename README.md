# 家庭管家 · 家庭日常管家系统

一个纯前端的家庭日常管家单页应用，帮助家庭协作管理家务、待办、购物清单、食品保质期和月度预算。

## 功能模块

- **控制台**：今日家务完成率、待办、待购、临期食品概览 + 预算使用情况
- **家务排班**：今日任务、月历视图、轮换分配规则、任务库
- **待办清单**：新建/编辑/删除待办，优先级、截止日期、重复、指派给成员
- **买菜记账**：共享购物清单（可添加物品）、账单管理、预算概览
- **食品管理**：库存食材、保质期预警、按状态筛选排序

## 本地运行

由于使用 Babel 以 XHR 方式加载外部 `.jsx` 文件，需要用 HTTP 服务打开（不要直接双击 `index.html`）：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node
npx serve .
```

然后浏览器访问 `http://localhost:8080`。

## 数据存储

- 业务数据（家务、排班、食品、待办、购物、账单、预算）自动保存到浏览器 `localStorage`
- Key：`family-housekeeper-data-v2`（登录态：`family-housekeeper-auth-v1`）
- 家庭成员、任务库等固定数据以代码为准，不持久化
- 头像菜单可「重置为演示数据」

## 技术栈

- React 18（CDN + Babel 运行时编译 JSX）
- ECharts（支出图表）
- 无后端、无构建步骤，纯静态页面
